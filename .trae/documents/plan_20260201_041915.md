# 在@Cacheable注解上设置缓存过期时间

## 问题分析

用户希望在`@Cacheable`注解上直接设置缓存过期时间，但Spring Cache的标准`@Cacheable`注解本身不支持直接设置过期时间参数。

## 修复方案

### 方案1：配置RedisCacheManager，为sys_dict缓存设置60分钟过期时间

**修改文件**：`blog/mojian-commom/src/main/java/com/mojian/config/RedisConfig.java`

**修改内容**：

1. **添加必要的导入**：
   ```java
   import org.springframework.cache.CacheManager;
   import org.springframework.cache.annotation.EnableCaching;
   import org.springframework.data.redis.cache.RedisCacheConfiguration;
   import org.springframework.data.redis.cache.RedisCacheManager;
   import org.springframework.data.redis.connection.RedisConnectionFactory;
   import org.springframework.data.redis.serializer.Jackson2JsonRedisSerializer;
   import org.springframework.data.redis.serializer.RedisSerializationContext;
   import org.springframework.data.redis.serializer.StringRedisSerializer;
   import java.time.Duration;
   import java.util.HashMap;
   import java.util.Map;
   ```

2. **添加@EnableCaching注解**：
   ```java
   @Configuration
   @EnableCaching
   public class RedisConfig {
   ```

3. **添加RedisCacheManager配置**：
   ```java
   @Bean
   public CacheManager cacheManager(RedisConnectionFactory factory) {
       // 为不同缓存设置不同过期时间
       Map<String, RedisCacheConfiguration> configMap = new HashMap<>();
       
       // 为sys_dict缓存设置60分钟过期时间
       configMap.put("sys_dict", RedisCacheConfiguration.defaultCacheConfig()
               .entryTtl(Duration.ofMinutes(60))
               .serializeKeysWith(RedisSerializationContext.SerializationPair.fromSerializer(new StringRedisSerializer()))
               .serializeValuesWith(RedisSerializationContext.SerializationPair.fromSerializer(new Jackson2JsonRedisSerializer(Object.class))));
       
       // 默认缓存配置（无过期时间）
       RedisCacheConfiguration defaultConfig = RedisCacheConfiguration.defaultCacheConfig()
               .serializeKeysWith(RedisSerializationContext.SerializationPair.fromSerializer(new StringRedisSerializer()))
               .serializeValuesWith(RedisSerializationContext.SerializationPair.fromSerializer(new Jackson2JsonRedisSerializer(Object.class)));
       
       // 构建缓存管理器
       return RedisCacheManager.builder(factory)
               .cacheDefaults(defaultConfig)
               .withInitialCacheConfigurations(configMap)
               .build();
   }
   ```

### 方案2：使用自定义注解和AOP切面

**创建文件**：`blog/mojian-commom/src/main/java/com/mojian/annotation/CacheExpire.java`

**内容**：
```java
import java.lang.annotation.ElementType;
import java.lang.annotation.Retention;
import java.lang.annotation.RetentionPolicy;
import java.lang.annotation.Target;

@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface CacheExpire {
    long value() default 60; // 默认60分钟
    String timeUnit() default "MINUTES"; // 默认分钟
}
```

**创建文件**：`blog/mojian-commom/src/main/java/com/mojian/aspect/CacheExpireAspect.java`

**内容**：
```java
import com.mojian.annotation.CacheExpire;
import com.mojian.utils.RedisUtil;
import lombok.RequiredArgsConstructor;
import org.aspectj.lang.JoinPoint;
import org.aspectj.lang.annotation.AfterReturning;
import org.aspectj.lang.annotation.Aspect;
import org.aspectj.lang.annotation.Pointcut;
import org.aspectj.lang.reflect.MethodSignature;
import org.springframework.cache.annotation.Cacheable;
import org.springframework.stereotype.Component;
import java.lang.reflect.Method;
import java.util.concurrent.TimeUnit;

@Aspect
@Component
@RequiredArgsConstructor
public class CacheExpireAspect {

    private final RedisUtil redisUtil;

    @Pointcut("@annotation(org.springframework.cache.annotation.Cacheable)")
    public void cacheablePointcut() {}

    @AfterReturning(pointcut = "cacheablePointcut()", returning = "result")
    public void setCacheExpire(JoinPoint joinPoint, Object result) {
        MethodSignature signature = (MethodSignature) joinPoint.getSignature();
        Method method = signature.getMethod();
        
        // 检查是否有@CacheExpire注解
        CacheExpire cacheExpire = method.getAnnotation(CacheExpire.class);
        if (cacheExpire != null) {
            // 获取@Cacheable注解
            Cacheable cacheable = method.getAnnotation(Cacheable.class);
            if (cacheable != null) {
                // 构建缓存键
                String[] cacheNames = cacheable.cacheNames();
                String key = cacheable.key();
                
                // 这里需要实现键的解析逻辑，简化版可以根据方法参数构建
                // 实际项目中可能需要更复杂的键解析
                String cacheKey = cacheNames[0] + ":" + key;
                
                // 设置过期时间
                long expireTime = cacheExpire.value();
                TimeUnit timeUnit = TimeUnit.valueOf(cacheExpire.timeUnit());
                redisUtil.expire(cacheKey, expireTime, timeUnit);
            }
        }
    }
}
```

### 推荐方案

**推荐方案1**：配置RedisCacheManager，为sys_dict缓存设置60分钟过期时间。

**推荐理由**：
1. **简单直接**：只需要修改RedisConfig配置类，不需要添加额外的依赖或代码。
2. **性能最优**：使用Spring内置的RedisCacheManager，性能更好。
3. **易于维护**：配置集中管理，易于理解和维护。
4. **兼容性好**：与现有的Spring Cache注解完全兼容。

**放弃方案2原因**：
1. **复杂度高**：需要创建自定义注解和AOP切面，增加了系统复杂度。
2. **性能开销**：AOP切面会增加方法调用的开销。
3. **键解析复杂**：需要实现缓存键的解析逻辑，容易出错。
4. **维护成本高**：需要维护额外的代码和逻辑。

2. 访问前端资源上传页面，触发字典数据缓存

## 预期结果

1. **过期时间设置**：`sys_dict`缓存的过期时间被设置为60分钟
2. **自动失效**：缓存会在60分钟后自动失效
3. **数据一致性**：缓存失效后，系统会重新从数据库加载最新数据
4. **内存优化**：避免缓存数据永久占用Redis内存

## 技术要点

- **RedisCacheManager**：Spring提供的Redis缓存管理器，支持设置基于缓存名称的过期时间
- **RedisCacheConfiguration**：配置缓存的序列化方式、过期时间等属性
- **Duration**：Java 8+的时间间隔类，用于设置过期时间
- **@EnableCaching**：启用Spring缓存支持

此方案通过配置RedisCacheManager，实现了为`sys_dict`缓存设置60分钟过期时间的需求，同时保持了与现有代码的完全兼容。
