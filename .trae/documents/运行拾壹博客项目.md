# 运行拾壹博客项目计划

## 项目概述
拾壹博客是一个前后端分离的博客系统，包含后端Spring Boot项目和两个前端Vue项目（后台管理和门户）。

## 运行步骤

### 1. 环境检查
- 检查JDK 1.8+是否安装
- 检查MySQL 5.5+是否安装并运行
- 检查Redis 6.0+是否安装并运行
- 检查Node.js 14+是否安装

### 2. 数据库配置
- 创建数据库：`CREATE DATABASE blog CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
- 导入数据库脚本：运行根目录下的 `mj-blog.sql` 文件
- 修改数据库连接配置：更新 `blog/mojian-server/src/main/resources/application-dev.yml` 中的数据库连接信息

### 3. 后端服务启动
- 进入后端项目目录：`cd blog/mojian-server`
- 编译项目：`mvn clean package`
- 运行后端服务：`java -jar target/mojian-server.jar`
- 验证后端服务：访问 `http://127.0.0.1:8800/shiyi/doc.html` 查看接口文档

### 4. 前端管理系统启动
- 进入后台管理前端目录：`cd blog-admin`
- 安装依赖：`npm install`
- 启动开发服务器：`npm run dev`
- 访问后台管理系统：`http://localhost:5173`

### 5. 前端门户系统启动
- 进入门户前端目录：`cd blog-web`
- 安装依赖：`npm install`
- 启动开发服务器：`npm run dev`
- 访问门户系统：`http://localhost:8080`

## 注意事项
- 请按照顺序启动服务：先启动后端，再启动前端
- 前端项目配置由后端动态加载
- 首次登录可使用账号：admin，密码：123456
- 如需使用七牛云存储和第三方登录功能，需要在配置文件中填写相应的API密钥

## 预期结果
- 后端服务成功启动，可访问接口文档
- 后台管理系统成功启动，可登录管理界面
- 门户系统成功启动，可浏览博客内容
