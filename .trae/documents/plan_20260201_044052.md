# 修复Redis缓存过期时间和键名格式问题

## 问题分析

用户反馈了两个问题：

1. **过期时间问题**：Redis中保存的数据没有设置过期时间（TTL显示"无TTL"）
2. **键名格式问题**：键名格式发生了变化，可能由之前的 `:` 变成了 `::`

## 问题原因

1. **过期时间问题**：

   * RedisCacheManager的配置可能没有正确应用到具体的缓存键上

   * 键名格式变化可能导致缓存配置不匹配

2. **键名格式问题**：

   * RedisCacheManager默认使用 `::` 作为键名分隔符

   * 与之前的键名格式不一致

## 修复方案

### 修改RedisConfig配置类，正确设置缓存过期时间和键名格式

**修改文件**：`blog/mojian-commom/src/main/java/com/mojian/config/RedisConfig.java`

**修改内容**：

1. **修改cacheManager方法**：

   ```java
   @Bean
   public CacheManager cacheManager(RedisConnectionFactory factory) {
       // 配置ObjectMapper，支持Java 8日期时间类型
       ObjectMapper objectMapper = new ObjectMapper();
       objectMapper.registerModule(new JavaTimeModule());
       objectMapper.disable(SerializationFeature.WRITE_DATES_AS_TIMESTAMPS);

       Jackson2JsonRedisSerializer<Object> serializer = new Jackson2JsonRedisSerializer<>(Object.class);
       serializer.setObjectMapper(objectMapper);

       // 为sys_dict缓存设置60分钟过期时间和正确的键名格式
       RedisCacheConfiguration sysDictConfig = RedisCacheConfiguration.defaultCacheConfig()
               .entryTtl(Duration.ofMinutes(60))
               .prefixCacheNameWith("") // 不添加前缀
               .serializeKeysWith(RedisSerializationContext.SerializationPair.fromSerializer(new StringRedisSerializer()))
               .serializeValuesWith(RedisSerializationContext.SerializationPair.fromSerializer(serializer));

       // 默认缓存配置
       RedisCacheConfiguration defaultConfig = RedisCacheConfiguration.defaultCacheConfig()
               .prefixCacheNameWith("") // 不添加前缀
               .serializeKeysWith(RedisSerializationContext.SerializationPair.fromSerializer(new StringRedisSerializer()))
               .serializeValuesWith(RedisSerializationContext.SerializationPair.fromSerializer(serializer));

       // 为不同缓存设置不同配置
       Map<String, RedisCacheConfiguration> configMap = new HashMap<>();
       configMap.put("sys_dict", sysDictConfig);
       
       // 构建缓存管理器
       return RedisCacheManager.builder(factory)
               .cacheDefaults(defaultConfig)
               .withInitialCacheConfigurations(configMap)
               .build();
   }
   ```

### 验证方法

1. **重启后端服务**
2. **清除现有缓存**：删除Redis中现有的 `sys_dict:sys_resource_category` 键
3. **触发缓存**：访问前端资源上传页面，触发资源分类缓存
4. **检查Redis**：

   * 验证新生成的键名格式是否正确（应使用 `:` 分隔符）

   * 验证TTL是否设置为60分钟

   * 验证数据是否正确存储

## 修复原理

1. **过期时间修复**：

   * 为 `sys_dict` 缓存明确设置60分钟过期时间

   * 确保缓存配置正确应用到具体的缓存键上

2. **键名格式修复**：

   * 设置 `prefixCacheNameWith("")` 不添加前缀

   * 确保键名格式与之前保持一致，使用 `:` 作为分隔符

## 预期结果

1. **过期时间正确**：Redis中的缓存数据会有60分钟的过期时间
2. **键名格式一致**：键名格式与之前保持一致，使用 `:` 作为分隔符
3. **数据正确**：缓存数据能够正确序列化和反序列化
4. **系统稳定**：缓存功能正常工作，无异常

此修复方案将解决Redis缓存过期时间和键名格式的问题，确保缓存功能按照预期工作。
